# uaRO Pad 0.2 (раскладка охотника) — план

> Исполнение: inline (executing-plans), TDD на каждом шаге, в конце — ревью всей ветки свежим ревьюером.

**Goal:** релиз 0.2.0 с раскладкой из спецификации.
**Spec:** `docs/superpowers/specs/2026-10-12-uaro-pad-v2-hunter-design.md` (главный документ; план только режет его на задачи).
**Ветка:** `feat/controls-v2` от `main` (a592747).

## Global Constraints

- C++17, ядро без Windows-заголовков, тесты — `cmake --build build-host && ./build-host/uapad_tests`.
- Windows-сборка — `tools/package.sh` (MinGW i686, статическая линковка, `tools/check_dll.sh`).
- Пакеты — раскладки packet_ver 22 (uAthena `db/packet_db.txt`), длины S→C — `clif.c` PACKETVER 7.
- Комментарии и стиль — как в окружающем коде; логи модуля — по-английски, README/ini — по-русски.

## Review Focus

1. Дописывание в `recv`: не на границе пакета, буфер без места, `MSG_PEEK`, чужой сокет, рассинхрон — клиент не должен получить ни байта лишнего.
2. Удержание кнопок: повтор не должен срабатывать во время подхода к цели и не должен дублировать нажатие в том же кадре.
3. Гистерезис правого стика и триггеров: дребезг около порога не даёт лишних «нажатий» и смен цели.
4. A удержана во время ходьбы и после смерти цели; R3 во время подхода.
5. Обучение камеры на выбросах (смена направления стика, нажатие в центре) и при повороте камеры.

## Задачи

### Task 1: протокол, настройки, мир
Files: `src/core/proto/c2s.{hpp,cpp}`, `src/core/proto/s2c_build.{hpp,cpp}` (новый), `src/core/config/config.{hpp,cpp}`,
`src/core/world/world.{hpp,cpp}`, `src/core/logic/pad.hpp`, `src/win/xinput_pad.cpp`, тесты `test_c2s.cpp`, `test_config.cpp`, `test_world.cpp`.

`Config::repeatMs/traps/mark`, `WorldState::lastMove() -> std::optional<Cell>`, `kPadLT/kPadRT`, `Rumble::{TargetCleared,PadOn,PadOff}`.
Tests: `c2s_name_request_and_stop_attack`, `s2c_build_emotion`, `config_v2_keys`, `world_last_move`.

### Task 2: угол камеры
Files: `src/core/logic/camera.{hpp,cpp}` (новый), `tests/test_camera.cpp`.
Produces: `class CameraYaw { void addSample(int sx, int sy, int wx, int wy); double radians() const; void toWorld(double sx, double sy, double& wx, double& wy) const; size_t samples() const; }`.

### Task 3: выбор цели по направлению

`uint32_t pickInDirection(const WorldState&, uint32_t nowMs, double dirX, double dirY, const std::unordered_map<uint32_t, uint32_t>& blacklistUntil)`; удаляет `cycleTarget`.

### Task 4: слоты 0.2
