# uaRO Pad — план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** прокси-`dinput.dll` для легаси-клиента `uaRO-1.1.exe`: игра с Xbox-геймпадом — ходьба стиком, скиллы и предметы со слотов панели горячих клавиш, атака с автовыбором монстра.

**Architecture:** переносимое ядро на C++17 (`src/core`: таблицы длин пакетов, нарезка TCP-потока, разбор и сборка пакетов, модель мира, логика контроллера, сессия) тестируется на Linux. Тонкий Windows-слой (`src/win`: экспорт `DirectInputCreateA`, обёртки DirectInput 7, IAT-хуки WinSock/USER32, XInput, связка с ядром) кросс-собирается MinGW в 32-битную `dinput.dll`. Сразу после базовых задач ядра собирается диагностическая сборка M0, чтобы на живом клиенте проверить, как он читает мышь и сокеты.

**Tech Stack:** C++17, CMake 3.31, host GCC 14.2 (тесты через CTest и самописный раннер), MinGW-w64 i686 GCC 12.2 (DLL), Python 3 (генератор таблиц), DirectInput 7 COM, WinSock IAT-хуки, XInput.

**Spec:** `docs/superpowers/specs/2026-10-12-uaro-pad-design.md`

## Global Constraints

- Клиент: легаси `uaRO-1.1.exe` (PE32 i386, Sakexe 2007, packet_ver 22). Сервер: uAthena, `PACKETVER 7` (`/root/uar/uAthena`).
- Поставка: `dinput.dll` + `uaro-pad.ini` в папку клиента; exe не меняется; удаление — удалить файлы.
- DLL 32-битная, C++17, статический рантайм (`-static -static-libgcc -static-libstdc++`); импортирует только системные DLL: `KERNEL32`, `USER32`, `WS2_32`, `msvcrt`.
- Геймпад: XInput, грузится динамически: `xinput1_4.dll` → `xinput1_3.dll` → `xinput9_1_0.dll`.
- Fail-open: любая ошибка модуля → режим «только транзит»; клиент продолжает работать.
- Разбирается только сокет карт-сервера (первый пакет клиента `0x009b`); трафик логин- и чар-сервера не разбирается и не логируется.
- Лог `uaro-pad.log` рядом с exe, перезаписывается при запуске; подробности — только при `log_level = debug`.
- Темп: атака не чаще `attack_interval_ms` (300); скилл/предмет не чаще 150 мс; шаги подхода не чаще 250 мс; подход отменяется через 5 с; подбор в радиусе 10 клеток, достаёт с 1 клетки.
- Автоцель: монстр = класс 1001–3999, `hair == 0`, не свой питомец; порядок — по расстоянию Чебышёва, при равенстве по ID; отказ от цели через 4 с без ударов; чёрный список на 10 с.
- Слоты: LT → 0–3, RT → 4–7, LB → 9–12, RB → 13–16; A, B, X, Y = +0…+3; триггер зажат при > 50 %; при нескольких модификаторах действует первый зажатый.
- Тесты: host GCC + CTest, без внешних тестовых зависимостей.
- Все команды выполняются из `/root/uaro-gamepad`.
- Каждый коммит заканчивается строкой `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

Случаи, которые легко упустить и которые сильнее всего ударят по игроку. Каждый закреплён тестом в задаче-владельце.

1. **Windows переиспользует номер сокета:** логин-сокет закрыт, а соединение с карт-сервером получило тот же номер. Модуль обязан распознать карт-сервер (хук `closesocket` → `Session::onClosed`). Тест `session_reused_socket_handle_after_close` (задача 12).
2. **Четыре «голых» байта ID аккаунта**, которые карт-сервер шлёт сразу после `0x009b`, приходят в разных `recv`. Нарезка не должна сбиться. Тесты `framer_raw_prefix_is_skipped` (задача 3) и `connect()` в тестах сессии (задача 12, ID разорван на 2+2 байта).
3. **Клиент как раз отправляет пакет по частям**, а модулю пора отправить свой. Свой пакет ждёт границы, устаревшие (> 500 мс) выбрасываются. Тесты `session_injection_waits_for_client_packet_boundary` и `session_drops_requests_that_waited_too_long` (задача 12).
4. **Неатакуемая «цель»**: НПЦ со спрайтом монстра или монстр за стеной. Модуль бросает её через 4 с и не выбирает 10 с. Тест `ctl_give_up_blacklists_unreachable_target` (задача 11).
5. **Переполнение `GetTickCount()`** (раз в 49,7 суток): таймеры считаются беззнаковой разностью. Тест `ctl_timers_survive_tick_wraparound` (задача 11).

## Уточнения относительно спецификации (проверено по исходникам uAthena)

- Карт-сервер после `0x009b` присылает 4 байта ID аккаунта без заголовка (`clif_parse_WantToConnection`: `WFIFOL(fd,0) = sd->bl.id`). `StreamFramer` пропускает этот префикс.
- Длины S→C берутся из жёсткой таблицы `packet_len_table[]` в `clif.c` (`packet_db[SERVER]`), а C→S — из `packet_db.txt`, накопленно по версиям до 22.
- Акторы-не-игроки при `PACKETVER 7` приходят только как `0x0078` (стоит), `0x007c` (появился) и `0x022c` (идёт). Остальные пакеты акторов (`0x0079`, `0x007b`, `0x01d8`–`0x01da`, `0x022a`, `0x022b` — только игроки) нужны лишь для нарезки потока.
- У питомцев в поле hair стоит `pet_hair_style` = 100 (`conf/battle/client.conf`), так что питомцев отсекаем по `hair != 0`, а не только по таймауту.
- В учёт ударов добавлен `0x0115` (урон скиллом с отбрасыванием), в состояние «мёртв» — `0x0148` (воскрешение).
- `0x0147` (скилл от предмета) нужен только для нарезки: на панель его не положить.
- Добавлен хук `closesocket` (см. Review Focus, п. 1).
- В ini добавлены два ключа для решения в M1: `[stick] press = ring | center` (вариант «а» из спецификации) и `[mouse] buttons = dinput | messages` (запасной канал кнопок мыши).
- Включение и выключение модуля кнопкой Back вибрирует так же, как включение и выключение автоатаки.
- Запросы модуля ждут в очереди границы пакетов клиента и выбрасываются, если ждали дольше 500 мс.
- Экипировка на панели (быстрая смена оружия) в v1 не поддерживается: слот с ней даёт вибрацию «нельзя».

```cpp
#pragma once
#include <cstddef>
#include <cstdint>
#include <vector>

namespace uapad {

using Bytes = std::vector<uint8_t>;

inline uint8_t rd8(const uint8_t* p, size_t o) { return p[o]; }
inline uint16_t rd16(const uint8_t* p, size_t o) { return uint16_t(p[o] | (p[o + 1] << 8)); }
inline uint32_t rd32(const uint8_t* p, size_t o) {
    return uint32_t(p[o]) | (uint32_t(p[o + 1]) << 8) | (uint32_t(p[o + 2]) << 16) | (uint32_t(p[o + 3]) << 24);
}
inline void wr8(Bytes& b, size_t o, uint8_t v) { b[o] = v; }
inline void wr16(Bytes& b, size_t o, uint16_t v) {
    b[o] = uint8_t(v);
    b[o + 1] = uint8_t(v >> 8);
}
inline void wr32(Bytes& b, size_t o, uint32_t v) {
    for (int i = 0; i < 4; ++i) b[o + i] = uint8_t(v >> (8 * i));
}

struct Cell {
    int x = 0;
    int y = 0;
};
inline bool operator==(const Cell& a, const Cell& b) { return a.x == b.x && a.y == b.y; }
inline bool operator!=(const Cell& a, const Cell& b) { return !(a == b); }

// Chebyshev distance: how uAthena measures ranges (battle_check_range, check_distance).
inline int cellDistance(const Cell& a, const Cell& b) {
    const int dx = a.x > b.x ? a.x - b.x : b.x - a.x;
    const int dy = a.y > b.y ? a.y - b.y : b.y - a.y;
    return dx > dy ? dx : dy;
}

// 3-byte packed position: WBUFPOS in uAthena src/map/clif.c.
inline Cell decodePos3(const uint8_t* p, size_t o) {
    const uint8_t* q = p + o;
    return Cell{q[0] * 4 + (q[1] >> 6), ((q[1] & 0x3f) << 4) + (q[2] >> 4)};
}
inline void encodePos3(Bytes& b, size_t o, Cell c, int dir) {
    b[o] = uint8_t(c.x >> 2);
    b[o + 1] = uint8_t((c.x << 6) | ((c.y >> 4) & 0x3f));
    b[o + 2] = uint8_t((c.y << 4) | (dir & 0x0f));
}

// 6-byte packed movement: WBUFPOS2 in uAthena src/map/clif.c.
struct Move {
    Cell from;
    Cell to;
};
inline Move decodePos6(const uint8_t* p, size_t o) {
    const uint8_t* q = p + o;
    Move m;
    m.from = Cell{q[0] * 4 + (q[1] >> 6), ((q[1] & 0x3f) << 4) + (q[2] >> 4)};
    m.to = Cell{((q[2] & 0x0f) << 6) + (q[3] >> 2), ((q[3] & 0x03) << 8) + q[4]};
    return m;
}
inline void encodePos6(Bytes& b, size_t o, Cell from, Cell to) {
    b[o] = uint8_t(from.x >> 2);
    b[o + 1] = uint8_t((from.x << 6) | ((from.y >> 4) & 0x3f));
    b[o + 2] = uint8_t((from.y << 4) | ((to.x >> 6) & 0x0f));
    b[o + 3] = uint8_t((to.x << 2) | ((to.y >> 8) & 0x03));
    b[o + 4] = uint8_t(to.y);
    b[o + 5] = 0x88;  // sub-cell offsets 8/8, as clif_walkok / clif_move send them
}

}  // namespace uapad
```

**Файл:** `tools/gen_packet_tables.py`
```python
#!/usr/bin/env python3
"""Generate src/core/proto/packet_tables.cpp from uAthena sources.

S2C lengths: the hardcoded packet_len_table[] in src/map/clif.c (packet_db[SERVER], used by
             WFIFOSET when the map server sends), resolved for PACKETVER from src/map/clif.h.
C2S lengths: db/packet_db.txt applied in file order. Every 'packet_ver: N' line copies the
             previous version, so the last version (22) is the cumulative result.

Usage: python3 -I tools/gen_packet_tables.py /root/uar/uAthena src/core/proto/packet_tables.cpp
"""
import re
import sys

TABLE_SIZE = 0x300


def read_packetver(root):
    text = open(f"{root}/src/map/clif.h", encoding="latin-1").read()
    m = re.search(r"#\s*define\s+PACKETVER\s+(\d+)", text)
    if not m:
        sys.exit("PACKETVER not found in clif.h")
    return int(m.group(1))


def read_s2c(root, packetver):
    text = open(f"{root}/src/map/clif.c", encoding="latin-1").read()
    body = text.split("int packet_len_table[MAX_PACKET_DB] = {", 1)[1].split("};", 1)[0]
    values, active = [], []
    for raw in body.splitlines():
        line = raw.strip()
        m = re.match(r"#if\s+PACKETVER\s*(<=|>=|==|<|>)\s*(\d+)", line)
        if m:
            op, num = m.group(1), int(m.group(2))
            active.append({"<": packetver < num, "<=": packetver <= num, ">": packetver > num,
                           ">=": packetver >= num, "==": packetver == num}[op])
            continue
        if line.startswith("#else"):
            active[-1] = not active[-1]
            continue
        if line.startswith("#endif"):
            active.pop()
            continue
        if active and not all(active):
            continue
        line = line.split("//", 1)[0]
        values += [int(v) for v in re.findall(r"-?\d+", line)]
    if len(values) != TABLE_SIZE:
        sys.exit(f"expected {TABLE_SIZE} S2C entries, got {len(values)}")
    return values


def read_c2s(root):
    lens = [0] * TABLE_SIZE
    for raw in open(f"{root}/db/packet_db.txt", encoding="latin-1"):
        line = raw.split("//", 1)[0].strip()
        if not line.startswith("0x"):
            continue
        parts = line.split(",")
        cmd = int(parts[0], 16)
        if 0 < cmd < TABLE_SIZE and len(parts) >= 2:
            lens[cmd] = int(parts[1])
    return lens


def emit(name, values):
    rows = []
    for i in range(0, TABLE_SIZE, 16):
        rows.append("    " + ", ".join(f"{v:4d}" for v in values[i:i + 16]) + f",  // 0x{i:04x}")
    return f"const int16_t {name}[{TABLE_SIZE}] = {{\n" + "\n".join(rows) + "\n};\n"


def main():
    root, out = sys.argv[1], sys.argv[2]
    packetver = read_packetver(root)
    s2c, c2s = read_s2c(root, packetver), read_c2s(root)
    with open(out, "w") as f:
        f.write("// GENERATED by tools/gen_packet_tables.py from uAthena sources. Do not edit.\n")
        f.write(f"// Server PACKETVER = {packetver}; client table = db/packet_db.txt up to packet_ver 22.\n")
        f.write('#include "core/proto/packet_tables.hpp"\n\nnamespace uapad {\nnamespace {\n\n')
        f.write(emit("kS2C", s2c))
        f.write("\n")
        f.write(emit("kC2S", c2s))
        f.write("\n}  // namespace\n\n")
        f.write("int s2cLength(uint16_t id) { return id < 0x300 ? kS2C[id] : 0; }\n")
        f.write("int c2sLength(uint16_t id) { return id < 0x300 ? kC2S[id] : 0; }\n\n")
        f.write("}  // namespace uapad\n")


if __name__ == "__main__":
    main()

#pragma once
#include <cstddef>
#include <cstdint>
#include <vector>

#include "core/bytes.hpp"

namespace uapad {

enum class Direction { ServerToClient, ClientToServer };

// Cuts a TCP byte stream into whole packets using the uAthena length tables.
class StreamFramer {
public:
    // rawPrefix: bytes at the very start of the stream that are not a packet
    // (the map server sends the 4-byte account id right after 0x009b).
    explicit StreamFramer(Direction dir, size_t rawPrefix = 0);

    // Appends complete packets to `out`. Returns false once the stream is desynchronized;
    // after that all input is ignored.
    bool feed(const uint8_t* data, size_t n, std::vector<Bytes>& out);

    bool desynced() const { return desynced_; }
    bool atBoundary() const { return buf_.empty() && prefixLeft_ == 0; }
    const Bytes& prefix() const { return prefix_; }
    uint16_t badId() const { return badId_; }

private:
    int lengthOf(uint16_t id) const;

    Direction dir_;
    size_t prefixLeft_;
    Bytes prefix_;
    Bytes buf_;
    bool desynced_ = false;
    uint16_t badId_ = 0;
};

}  // namespace uapad
```

**Файл:** `src/core/proto/framer.cpp`
```cpp
#include "core/proto/framer.hpp"

#include "core/proto/packet_tables.hpp"

namespace uapad {

namespace {
constexpr size_t kMaxPacket = 0x8000;
}  // namespace

StreamFramer::StreamFramer(Direction dir, size_t rawPrefix) : dir_(dir), prefixLeft_(rawPrefix) {}

int StreamFramer::lengthOf(uint16_t id) const {
    return dir_ == Direction::ServerToClient ? s2cLength(id) : c2sLength(id);
}

bool StreamFramer::feed(const uint8_t* data, size_t n, std::vector<Bytes>& out) {
    if (desynced_) return false;
    size_t i = 0;
    while (prefixLeft_ > 0 && i < n) {
        prefix_.push_back(data[i++]);
        --prefixLeft_;
    }
    buf_.insert(buf_.end(), data + i, data + n);
    size_t pos = 0;
    while (buf_.size() - pos >= 2) {
        const uint16_t id = rd16(buf_.data(), pos);
        const int len = lengthOf(id);
        size_t need = 0;
        if (len > 0) {
            need = size_t(len);
        } else if (len == -1) {
            if (buf_.size() - pos < 4) break;
            need = rd16(buf_.data(), pos + 2);
            if (need < 4 || need > kMaxPacket) {
                desynced_ = true;
                badId_ = id;
                break;
            }
        } else {
            desynced_ = true;
            badId_ = id;
            break;
        }
        if (buf_.size() - pos < need) break;
        out.emplace_back(buf_.begin() + long(pos), buf_.begin() + long(pos + need));
        pos += need;
    }
    if (desynced_) {
        buf_.clear();
        return false;
    }
    buf_.erase(buf_.begin(), buf_.begin() + long(pos));
    return true;
}

}  // namespace uapad

#include <cstdlib>
#include <sstream>

namespace uapad {
namespace {

std::string trim(const std::string& s) {
    const size_t a = s.find_first_not_of(" \t\r\n");
    if (a == std::string::npos) return "";
    const size_t b = s.find_last_not_of(" \t\r\n");
    return s.substr(a, b - a + 1);
}

void setFloat(const std::string& v, float lo, float hi, float& out) {
    char* end = nullptr;
    const float f = std::strtof(v.c_str(), &end);
    if (end != v.c_str() && *end == '\0' && f >= lo && f <= hi) out = f;
}

bool toInt(const std::string& v, int lo, int hi, int& out) {
    char* end = nullptr;
    const long n = std::strtol(v.c_str(), &end, 10);
    if (end == v.c_str() || *end != '\0' || n < lo || n > hi) return false;
    out = int(n);
    return true;
}

void setBool(const std::string& v, bool& out) {
    if (v == "1" || v == "true" || v == "on") out = true;
    if (v == "0" || v == "false" || v == "off") out = false;
}

void setIdList(const std::string& v, std::vector<uint16_t>& out) {
    std::vector<uint16_t> ids;
    std::istringstream list(v);
    std::string item;
    while (std::getline(list, item, ',')) {
        int id = 0;
        if (!toInt(trim(item), 1, 65535, id)) return;
        ids.push_back(uint16_t(id));
    }
    out = ids;
}

}  // namespace

Config parseConfig(const std::string& text) {
    Config c;
    std::istringstream in(text);
    std::string line;
    std::string section;
    while (std::getline(in, line)) {
        const size_t comment = line.find(';');
        if (comment != std::string::npos) line = line.substr(0, comment);
        line = trim(line);
        if (line.empty()) continue;
        if (line.front() == '[' && line.back() == ']') {
            section = trim(line.substr(1, line.size() - 2));
            continue;
        }
        const size_t eq = line.find('=');
        if (eq == std::string::npos) continue;
        const std::string key = section + "." + trim(line.substr(0, eq));
        const std::string val = trim(line.substr(eq + 1));
        if (key == "general.enabled") {
            setBool(val, c.enabled);
        } else if (key == "general.log_level") {
            if (val == "error") c.logLevel = LogLevel::Error;
            if (val == "info") c.logLevel = LogLevel::Info;
            if (val == "debug") c.logLevel = LogLevel::Debug;
        } else if (key == "stick.deadzone") {
            setFloat(val, 0.05f, 0.9f, c.deadzone);
        } else if (key == "stick.walk_radius") {
            setFloat(val, 0.05f, 0.45f, c.walkRadius);
        } else if (key == "stick.press") {

#include "win/iat.hpp"

namespace uapad::iat {

void* patch(HMODULE module, void* target, void* replacement) {
    auto* base = reinterpret_cast<BYTE*>(module);
    auto* dos = reinterpret_cast<IMAGE_DOS_HEADER*>(base);
    if (dos->e_magic != IMAGE_DOS_SIGNATURE) return nullptr;
    auto* nt = reinterpret_cast<IMAGE_NT_HEADERS*>(base + dos->e_lfanew);
    const IMAGE_DATA_DIRECTORY& dir = nt->OptionalHeader.DataDirectory[IMAGE_DIRECTORY_ENTRY_IMPORT];
    if (!dir.VirtualAddress) return nullptr;
    bool patched = false;
    for (auto* imp = reinterpret_cast<IMAGE_IMPORT_DESCRIPTOR*>(base + dir.VirtualAddress); imp->Name; ++imp) {
        for (auto* thunk = reinterpret_cast<IMAGE_THUNK_DATA*>(base + imp->FirstThunk); thunk->u1.Function; ++thunk) {
            if (reinterpret_cast<void*>(thunk->u1.Function) != target) continue;
            DWORD old = 0;
            if (!VirtualProtect(&thunk->u1.Function, sizeof(thunk->u1.Function), PAGE_READWRITE, &old)) continue;
            thunk->u1.Function = reinterpret_cast<ULONG_PTR>(replacement);
            VirtualProtect(&thunk->u1.Function, sizeof(thunk->u1.Function), old, &old);
            patched = true;
        }
    }
    return patched ? target : nullptr;
}

}  // namespace uapad::iat

#include "win/iat.hpp"

namespace uapad::hooks {
namespace {

using recv_t = int(WSAAPI*)(SOCKET, char*, int, int);
using send_t = int(WSAAPI*)(SOCKET, const char*, int, int);
using wsasend_t = int(WSAAPI*)(SOCKET, LPWSABUF, DWORD, LPDWORD, DWORD, LPWSAOVERLAPPED, LPWSAOVERLAPPED_COMPLETION_ROUTINE);
using closesocket_t = int(WSAAPI*)(SOCKET);
using getcursorpos_t = BOOL(WINAPI*)(LPPOINT);
using peekmessage_t = BOOL(WINAPI*)(LPMSG, HWND, UINT, UINT, UINT);
using wsagetlasterror_t = int(WSAAPI*)();

recv_t o_recv = nullptr;
send_t o_send = nullptr;
wsasend_t o_wsasend = nullptr;
closesocket_t o_closesocket = nullptr;
getcursorpos_t o_getcursorpos = nullptr;
peekmessage_t o_peekmessage = nullptr;
wsagetlasterror_t o_wsagetlasterror = nullptr;

int WSAAPI h_recv(SOCKET s, char* buf, int len, int flags) {
    const int n = o_recv(s, buf, len, flags);
    if (n > 0 && !(flags & MSG_PEEK)) runtime::onRecv(s, buf, n);
    return n;
}

int WSAAPI h_send(SOCKET s, const char* buf, int len, int flags) {
    const int n = o_send(s, buf, len, flags);
    if (n > 0) runtime::onSent(s, buf, n);
    return n;
}

int WSAAPI h_wsasend(SOCKET s, LPWSABUF bufs, DWORD count, LPDWORD sent, DWORD flags, LPWSAOVERLAPPED ov,
                     LPWSAOVERLAPPED_COMPLETION_ROUTINE done) {
    const int r = o_wsasend(s, bufs, count, sent, flags, ov, done);
    if (r == 0 && sent && !ov) runtime::onSentBuffers(s, bufs, count, *sent);
    return r;
}

int WSAAPI h_closesocket(SOCKET s) {
    runtime::onClose(s);
    return o_closesocket(s);
}

BOOL WINAPI h_getcursorpos(LPPOINT p) {
    const BOOL ok = o_getcursorpos(p);
    if (ok) runtime::onGetCursorPos(p);
    return ok;
}

BOOL WINAPI h_peekmessage(LPMSG msg, HWND hwnd, UINT first, UINT last, UINT remove) {
    runtime::onMessagePump();
    return o_peekmessage(msg, hwnd, first, last, remove);
}

template <class T>
T proc(HMODULE dll, const char* name) {
    return reinterpret_cast<T>(reinterpret_cast<void*>(GetProcAddress(dll, name)));
}

template <class T>
void hook(HMODULE dll, const char* name, T replacement, T& original) {
    T target = proc<T>(dll, name);
    original = target;
    if (!target) {
        LOG_ERROR("hook %s: export not found", name);
        return;
    }
    if (iat::patch(GetModuleHandleA(nullptr), reinterpret_cast<void*>(target), reinterpret_cast<void*>(replacement)))
        LOG_INFO("hooked %s", name);
    else
        LOG_ERROR("hook %s: not in the client's import table", name);
}

}  // namespace

void install() {
    HMODULE ws2 = GetModuleHandleA("ws2_32.dll");
    if (!ws2) ws2 = LoadLibraryA("ws2_32.dll");
    HMODULE user32 = GetModuleHandleA("user32.dll");
    o_wsagetlasterror = proc<wsagetlasterror_t>(ws2, "WSAGetLastError");
    hook(ws2, "recv", &h_recv, o_recv);
    hook(ws2, "send", &h_send, o_send);
    hook(ws2, "WSASend", &h_wsasend, o_wsasend);
    hook(ws2, "closesocket", &h_closesocket, o_closesocket);
    hook(user32, "GetCursorPos", &h_getcursorpos, o_getcursorpos);
    hook(user32, "PeekMessageA", &h_peekmessage, o_peekmessage);
}

int lastError() { return o_wsagetlasterror ? o_wsagetlasterror() : 0; }

bool sendAll(SOCKET s, const uint8_t* data, int len) {
    if (!o_send) return false;
    int done = 0;
    int retries = 0;
    while (done < len) {
        const int n = o_send(s, reinterpret_cast<const char*>(data) + done, len - done, 0);
        if (n > 0) {
            done += n;
            continue;
        }
        if (n == SOCKET_ERROR && lastError() == WSAEWOULDBLOCK && ++retries <= 50) {
            Sleep(1);
            continue;
        }
        return false;
    }
    return true;
}

}  // namespace uapad::hooks

    if (IsEqualGUID(guid, GUID_SysKeyboard)) {
        LOG_INFO("keyboard device created");
        return new DeviceWrap(dev, DevKind::Keyboard);
    }
    return dev;
}

class InputWrap final : public IDirectInput7A {
public:
    explicit InputWrap(IDirectInputA* real) : real_(real) {}

    STDMETHODIMP QueryInterface(REFIID riid, LPVOID* ppv) override {
        if (!ppv) return E_POINTER;
        const bool base = IsEqualGUID(riid, IID_IUnknown) || IsEqualGUID(riid, IID_IDirectInputA);
        const bool newer = IsEqualGUID(riid, IID_IDirectInput2A) || IsEqualGUID(riid, IID_IDirectInput7A);
        if (base || (newer && ensure(riid))) {
            AddRef();
            *ppv = static_cast<IDirectInput7A*>(this);
            return S_OK;
        }
        return real_->QueryInterface(riid, ppv);
    }
    STDMETHODIMP_(ULONG) AddRef() override { return ULONG(InterlockedIncrement(&refs_)); }
    STDMETHODIMP_(ULONG) Release() override {
        const LONG n = InterlockedDecrement(&refs_);
        if (n == 0) {
            if (v7_) v7_->Release();
            if (v2_) v2_->Release();
            real_->Release();
            delete this;
        }
        return ULONG(n);
    }
    STDMETHODIMP CreateDevice(REFGUID guid, LPDIRECTINPUTDEVICEA* out, LPUNKNOWN outer) override {
        const HRESULT hr = real_->CreateDevice(guid, out, outer);
        if (SUCCEEDED(hr) && out && *out && !outer) *out = wrapDevice(guid, *out);
        return hr;
    }
    STDMETHODIMP EnumDevices(DWORD type, LPDIENUMDEVICESCALLBACKA cb, LPVOID ref, DWORD flags) override {
        return real_->EnumDevices(type, cb, ref, flags);
    }
    STDMETHODIMP GetDeviceStatus(REFGUID guid) override { return real_->GetDeviceStatus(guid); }
    STDMETHODIMP RunControlPanel(HWND owner, DWORD flags) override { return real_->RunControlPanel(owner, flags); }
    STDMETHODIMP Initialize(HINSTANCE inst, DWORD version) override { return real_->Initialize(inst, version); }
    STDMETHODIMP FindDevice(REFGUID guid, LPCSTR name, LPGUID out) override {
        return ensure(IID_IDirectInput2A) ? v2_->FindDevice(guid, name, out) : E_NOTIMPL;
    }
    STDMETHODIMP CreateDeviceEx(REFGUID guid, REFIID riid, LPVOID* out, LPUNKNOWN outer) override {
        if (!ensure(IID_IDirectInput7A)) return E_NOTIMPL;
        if (outer) return v7_->CreateDeviceEx(guid, riid, out, outer);
        IDirectInputDeviceA* dev = nullptr;
        HRESULT hr = v7_->CreateDeviceEx(guid, IID_IDirectInputDeviceA, reinterpret_cast<LPVOID*>(&dev), nullptr);
        if (FAILED(hr) || !dev) return hr;
        IDirectInputDeviceA* wrapped = wrapDevice(guid, dev);
        hr = wrapped->QueryInterface(riid, out);
        wrapped->Release();
        return hr;
    }

private:
    bool ensure(REFIID riid) {
        if (IsEqualGUID(riid, IID_IDirectInput7A)) {
            if (!v7_ && FAILED(real_->QueryInterface(IID_IDirectInput7A, reinterpret_cast<void**>(&v7_)))) v7_ = nullptr;
            return v7_ != nullptr;
        }
        if (!v2_ && FAILED(real_->QueryInterface(IID_IDirectInput2A, reinterpret_cast<void**>(&v2_)))) v2_ = nullptr;
        return v2_ != nullptr;
    }

    IDirectInputA* real_;
    IDirectInput2A* v2_ = nullptr;
    IDirectInput7A* v7_ = nullptr;
    LONG refs_ = 1;
};

    uapad::runtime::init();

namespace uapad {
namespace {

float axis(SHORT v) { return v < 0 ? float(v) / 32768.0f : float(v) / 32767.0f; }

struct ButtonMap {
    WORD xinput;
    uint16_t ours;
};

const ButtonMap kButtons[] = {
    {XINPUT_GAMEPAD_A, kPadA},
    {XINPUT_GAMEPAD_B, kPadB},
    {XINPUT_GAMEPAD_X, kPadX},
    {XINPUT_GAMEPAD_Y, kPadY},
    {XINPUT_GAMEPAD_LEFT_SHOULDER, kPadLB},
    {XINPUT_GAMEPAD_RIGHT_SHOULDER, kPadRB},
    {XINPUT_GAMEPAD_BACK, kPadBack},
    {XINPUT_GAMEPAD_START, kPadStart},
    {XINPUT_GAMEPAD_DPAD_UP, kPadUp},
    {XINPUT_GAMEPAD_DPAD_DOWN, kPadDown},
    {XINPUT_GAMEPAD_DPAD_LEFT, kPadLeft},
    {XINPUT_GAMEPAD_DPAD_RIGHT, kPadRight},
    {XINPUT_GAMEPAD_LEFT_THUMB, kPadL3},
    {XINPUT_GAMEPAD_RIGHT_THUMB, kPadR3},
};

}  // namespace

bool XInputPad::load() {
    static const char* const kDlls[] = {"xinput1_4.dll", "xinput1_3.dll", "xinput9_1_0.dll"};
    for (const char* dll : kDlls) {
        HMODULE m = LoadLibraryA(dll);
        if (!m) continue;
        getState_ = reinterpret_cast<GetState_t>(reinterpret_cast<void*>(GetProcAddress(m, "XInputGetState")));
        setState_ = reinterpret_cast<SetState_t>(reinterpret_cast<void*>(GetProcAddress(m, "XInputSetState")));
        if (getState_) {
            name_ = dll;
            return true;
        }
    }
    return false;
}

PadState XInputPad::poll() {
    PadState p;
    if (!getState_) return p;
    XINPUT_STATE st{};
    if (index_ >= 0 && getState_(DWORD(index_), &st) != ERROR_SUCCESS) index_ = -1;
    if (index_ < 0) {
        // Polling empty XInput slots is slow: look for a controller at most once a second.
        const DWORD now = GetTickCount();
        if (scanned_ && now - lastScanMs_ < 1000) return p;
        scanned_ = true;
        lastScanMs_ = now;
        for (DWORD i = 0; i < 4 && index_ < 0; ++i)
            if (getState_(i, &st) == ERROR_SUCCESS) index_ = int(i);
        if (index_ < 0) return p;
    }
    const XINPUT_GAMEPAD& g = st.Gamepad;
    p.connected = true;
    for (const ButtonMap& b : kButtons)
        if (g.wButtons & b.xinput) p.buttons = uint16_t(p.buttons | b.ours);
    p.lx = axis(g.sThumbLX);
    p.ly = axis(g.sThumbLY);
    p.rx = axis(g.sThumbRX);
    p.ry = axis(g.sThumbRY);
    p.lt = float(g.bLeftTrigger) / 255.0f;
    p.rt = float(g.bRightTrigger) / 255.0f;
    return p;
}

void XInputPad::rumble(Rumble pattern, DWORD nowMs) {
    pattern_.clear();
    switch (pattern) {
        case Rumble::TargetSwitch: pattern_ = {{80, 0, 0x6000}}; break;
        case Rumble::AutoOn: pattern_ = {{60, 0x5000, 0x5000}, {60, 0, 0}, {60, 0x5000, 0x5000}}; break;
        case Rumble::AutoOff: pattern_ = {{250, 0x8000, 0}}; break;
        case Rumble::Denied: pattern_ = {{40, 0, 0x3000}}; break;
        case Rumble::None: break;
    }
    seg_ = 0;
    segStart_ = nowMs;
    if (!pattern_.empty()) setMotors(pattern_[0].left, pattern_[0].right);
}

void XInputPad::update(DWORD nowMs) {
    if (pattern_.empty()) return;
    while (seg_ < pattern_.size() && nowMs - segStart_ >= pattern_[seg_].ms) {
        segStart_ += pattern_[seg_].ms;
        ++seg_;
        if (seg_ < pattern_.size()) setMotors(pattern_[seg_].left, pattern_[seg_].right);
    }
    if (seg_ >= pattern_.size()) stopRumble();
}

void XInputPad::stopRumble() {
    pattern_.clear();
    setMotors(0, 0);
}

void XInputPad::setMotors(WORD left, WORD right) {
    if (!setState_ || index_ < 0) return;
    XINPUT_VIBRATION v{left, right};
    setState_(DWORD(index_), &v);
}

// M0 diagnostics build: everything passes through untouched. The log records how the client reads
// the mouse and which packet opens each connection, so task 13 can rely on facts.
namespace uapad::runtime {
namespace {

struct State {
    bool initDone = false;
    bool failed = false;
    DWORD gameThread = 0;
    bool warnedThread = false;
    HWND hwnd = nullptr;
    Config cfg;
    XInputPad pad;
    bool loggedConnected = false;
    uint16_t loggedButtons = 0;
    bool ticked = false;
    DWORD lastTickMs = 0;
    std::unordered_map<SOCKET, bool> seenSockets;
    unsigned long nState = 0, nData = 0, nCursor = 0, nPump = 0, nRecv = 0, nSend = 0;
    DWORD lastDiagMs = 0;
};

State& S() {
    static State s;
    return s;
}

std::string exeDir() {
    char path[MAX_PATH] = {0};
    GetModuleFileNameA(nullptr, path, MAX_PATH);
    const std::string p(path);
    const size_t slash = p.find_last_of("\\/");
    return slash == std::string::npos ? std::string() : p.substr(0, slash + 1);
}

std::string readFile(const std::string& path) {
    std::ifstream f(path, std::ios::binary);
    std::ostringstream ss;
    ss << f.rdbuf();
    return ss.str();
}

bool onGameThread() {
    State& s = S();
    if (GetCurrentThreadId() == s.gameThread) return true;
    if (!s.warnedThread) {
        s.warnedThread = true;
        LOG_INFO("a hook was called from a non-game thread (%lu); such calls are ignored",
                 (unsigned long)GetCurrentThreadId());
    }
    return false;
}

template <class F>
void guarded(const char* where, F&& body) {
    State& s = S();
    if (!s.initDone || s.failed) return;
    try {
        body();
    } catch (...) {
        LOG_ERROR("internal error in %s; pass-through until the client restarts", where);
        s.failed = true;
    }
}

void logDiagnostics(DWORD now) {
    State& s = S();
    if (s.lastDiagMs != 0 && now - s.lastDiagMs < 10000) return;
    s.lastDiagMs = now;
    LOG_INFO("diag: mouse GetDeviceState=%lu GetDeviceData=%lu | GetCursorPos=%lu | PeekMessageA=%lu | recv=%lu send=%lu",
             s.nState, s.nData, s.nCursor, s.nPump, s.nRecv, s.nSend);
}

void tick() {
    State& s = S();
    const DWORD now = GetTickCount();
    if (s.ticked && now - s.lastTickMs < 5) return;
    s.ticked = true;
    s.lastTickMs = now;
    const PadState p = s.pad.poll();
    if (p.connected != s.loggedConnected) {
        s.loggedConnected = p.connected;
        LOG_INFO("gamepad %s", p.connected ? "connected" : "disconnected");
    }
    if (p.buttons != s.loggedButtons) {
        if ((p.buttons & kPadA) && !(s.loggedButtons & kPadA)) s.pad.rumble(Rumble::TargetSwitch, now);
        s.loggedButtons = p.buttons;
        LOG_INFO("buttons 0x%04x lx=%.2f ly=%.2f lt=%.2f rt=%.2f", unsigned(p.buttons), p.lx, p.ly, p.lt, p.rt);
    }
    s.pad.update(now);
    logDiagnostics(now);
}

}  // namespace

bool healthy() { return S().initDone && !S().failed; }

void init() {
    State& s = S();
    if (s.initDone || s.failed) return;
    try {
        const std::string dir = exeDir();
        s.cfg = parseConfig(readFile(dir + "uaro-pad.ini"));
        wlog::open(dir + "uaro-pad.log", s.cfg.logLevel);
        LOG_INFO("uaRO Pad %s, M0 diagnostics build", version());
        s.gameThread = GetCurrentThreadId();
        hooks::install();
        if (s.pad.load())
            LOG_INFO("XInput: %s", s.pad.dllName());
        else
            LOG_INFO("XInput not found: gamepad unavailable");
        s.initDone = true;
    } catch (...) {
        s.failed = true;
        LOG_ERROR("init failed; pass-through only");
    }
}

void setGameWindow(HWND hwnd) {
    State& s = S();
    if (s.hwnd == hwnd) return;
    s.hwnd = hwnd;
    LOG_INFO("game window %p", static_cast<void*>(hwnd));
}

void onMouseState(DWORD cb, LPVOID data) {
    (void)data;
    State& s = S();
    if (s.nState++ == 0) LOG_INFO("first mouse GetDeviceState, %lu bytes", (unsigned long)cb);
    guarded("mouse state", [&] {
        if (onGameThread()) tick();
    });
}

void onMouseData(DWORD cbObjectData, LPDIDEVICEOBJECTDATA rgdod, LPDWORD inOut, DWORD capacity, DWORD flags) {
    (void)rgdod;
    State& s = S();
    if (s.nData++ == 0)
        LOG_INFO("first mouse GetDeviceData: object %lu bytes, capacity %lu, got %lu, flags 0x%lx",
                 (unsigned long)cbObjectData, (unsigned long)capacity, (unsigned long)(inOut ? *inOut : 0),
                 (unsigned long)flags);
    guarded("mouse data", [&] {
        if (onGameThread()) tick();
    });
}

void onGetCursorPos(LPPOINT p) {
    (void)p;
    ++S().nCursor;
}

void onMessagePump() {
    State& s = S();
    ++s.nPump;
    guarded("message pump", [&] {
        if (onGameThread() && (!s.ticked || GetTickCount() - s.lastTickMs >= 50)) tick();

}

void onRecv(SOCKET sock, const char* buf, int n) {
    (void)sock;
    (void)buf;
    (void)n;
    ++S().nRecv;
}

void onSent(SOCKET sock, const char* buf, int n) {

    ++s.nSend;

}

#!/usr/bin/env bash
# Checks the cross-built proxy: it exports DirectInputCreateA and imports only system DLLs.
set -euo pipefail
dll="${1:-build-win/dinput.dll}"
[ -f "$dll" ] || { echo "FAIL: $dll not found"; exit 1; }

info=$(i686-w64-mingw32-objdump -p "$dll")
if ! grep -q -E '^\s+\[ *[0-9]+\] DirectInputCreateA$' <<<"$info"; then
    echo "FAIL: DirectInputCreateA is not exported"
    exit 1
fi
imports=$(awk '/DLL Name:/ {print $3}' <<<"$info")
bad=$(grep -v -i -E '^(KERNEL32|USER32|WS2_32|msvcrt)\.dll$' <<<"$imports" || true)
if [ -n "$bad" ]; then
    echo "FAIL: unexpected imports: $bad"
    exit 1
fi
echo "OK: $dll exports DirectInputCreateA; imports: $(echo $imports)"

| Что в логе | Вывод |
|---|---|
| `hooked recv/send/WSASend/closesocket/GetCursorPos/PeekMessageA` | хуки встали; если какой-то `not in the client's import table` — записать, задача 13 без него обойдётся, кроме `recv`/`send` (тогда стоп, пересмотреть план) |

#include "core/proto/c2s.hpp"

namespace uapad {

Bytes buildWalk(Cell to) {
    Bytes b(8, 0);
    wr16(b, 0, 0x00a7);
    encodePos3(b, 5, to, 0);
    return b;
}

Bytes buildAction(uint32_t target, uint8_t type) {
    Bytes b(19, 0);
    wr16(b, 0, 0x0190);
    wr32(b, 5, target);
    wr8(b, 18, type);
    return b;
}

Bytes buildSkillToId(uint16_t skill, uint16_t lv, uint32_t target) {
    Bytes b(25, 0);
    wr16(b, 0, 0x0072);
    wr16(b, 6, lv);
    wr16(b, 10, skill);
    wr32(b, 21, target);
    return b;
}

Bytes buildSkillToPos(uint16_t skill, uint16_t lv, Cell at) {
    Bytes b(22, 0);
    wr16(b, 0, 0x0113);
    wr16(b, 5, lv);
    wr16(b, 9, skill);
    wr16(b, 12, uint16_t(at.x));
    wr16(b, 20, uint16_t(at.y));
    return b;
}

Bytes buildTakeItem(uint32_t floorId) {
    Bytes b(8, 0);
    wr16(b, 0, 0x00f5);
    wr32(b, 4, floorId);
    return b;
}

Bytes buildUseItem(uint16_t index, uint32_t accountId) {
    Bytes b(14, 0);
    wr16(b, 0, 0x009f);
    wr16(b, 4, index);
    wr32(b, 10, accountId);
    return b;
}

std::optional<uint32_t> parseWantToConnection(const Bytes& p) {
    if (p.size() < 26 || rd16(p.data(), 0) != 0x009b) return std::nullopt;
    return rd32(p.data(), 4);
}

std::optional<HotkeyChange> parseHotkeyChange(const Bytes& p) {
    if (p.size() < 11 || rd16(p.data(), 0) != 0x02ba) return std::nullopt;
    HotkeyChange c;
    c.index = rd16(p.data(), 2);
    c.key.type = rd8(p.data(), 4);
    c.key.id = rd32(p.data(), 5);
    c.key.lv = rd16(p.data(), 9);
    return c;
}

std::optional<Cell> parseWalkRequest(const Bytes& p) {
    if (p.size() < 8 || rd16(p.data(), 0) != 0x00a7) return std::nullopt;
    return decodePos3(p.data(), 5);
}

}  // namespace uapad

#include "core/proto/s2c_parser.hpp"

namespace uapad {
namespace {

std::string mapName(const Bytes& p, size_t o) {
    std::string s;
    for (size_t i = o; i < o + 16 && i < p.size() && p[i] != 0; ++i) s.push_back(char(p[i]));
    return s;
}

}  // namespace

std::optional<Event> parseS2C(const Bytes& p) {
    if (p.size() < 2) return std::nullopt;
    const uint8_t* d = p.data();
    const size_t n = p.size();
    switch (rd16(d, 0)) {
        case 0x0073:
            if (n < 11) break;
            return EvAuthOk{decodePos3(d, 6)};
        case 0x0091:
            if (n < 22) break;
            return EvMapChange{mapName(p, 2), Cell{rd16(d, 18), rd16(d, 20)}};
        case 0x0092:
            if (n < 28) break;
            return EvMapChange{mapName(p, 2), Cell{rd16(d, 18), rd16(d, 20)}};
        case 0x0087: {
            if (n < 12) break;
            const Move m = decodePos6(d, 6);
            return EvSelfWalk{m.from, m.to};
        }
        case 0x0088:
        case 0x01ff:
            if (n < 10) break;
            return EvSetPos{rd32(d, 2), Cell{rd16(d, 6), rd16(d, 8)}};
        case 0x0080:
            if (n < 7) break;
            return EvVanish{rd32(d, 2), rd8(d, 6)};
        case 0x0078: {
            if (n < 54) break;
            const Cell c = decodePos3(d, 46);
            return EvActor{rd32(d, 2), rd16(d, 14), rd16(d, 16), rd16(d, 6), c, c};
        }
        case 0x007c: {
            if (n < 41) break;
            const Cell c = decodePos3(d, 36);
            return EvActor{rd32(d, 2), rd16(d, 20), rd16(d, 14), rd16(d, 6), c, c};
        }
        case 0x022c: {
            if (n < 64) break;
            const Move m = decodePos6(d, 54);
            return EvActor{rd32(d, 2), rd16(d, 16), rd16(d, 18), rd16(d, 6), m.from, m.to};
        }
        case 0x0086: {
            if (n < 16) break;
            const Move m = decodePos6(d, 6);
            return EvActorMove{rd32(d, 2), m.from, m.to};
        }
        case 0x01a4:
            if (n < 11) break;
            return EvPetInfo{rd8(d, 2), rd32(d, 3)};
        case 0x008a:
            if (n < 29) break;
            return EvAction{rd32(d, 2), rd32(d, 6), rd8(d, 26)};
        case 0x01de:
        case 0x0114:
        case 0x0115:
            if (n < 12) break;
            return EvSkillHit{rd16(d, 2), rd32(d, 4), rd32(d, 8)};
        case 0x009d:
        case 0x009e:
            if (n < 17) break;
            return EvGroundItem{rd32(d, 2), rd16(d, 6), Cell{rd16(d, 9), rd16(d, 11)}};
        case 0x00a1:
            if (n < 6) break;
            return EvGroundItemGone{rd32(d, 2)};
        case 0x01ee: {
            EvInventory ev;
            for (size_t o = 4; o + 18 <= n; o += 18)
                ev.items.push_back(InvEntry{rd16(d, o), rd16(d, o + 2), rd16(d, o + 6), false});
            return ev;
        }
        case 0x00a0:
            if (n < 23 || rd8(d, 22) != 0) break;  // non-zero = the item was not added
            return EvItemAdd{InvEntry{rd16(d, 2), rd16(d, 6), rd16(d, 4), rd16(d, 19) != 0}};
        case 0x00af:
            if (n < 6) break;
            return EvItemRemove{rd16(d, 2), rd16(d, 4)};
        case 0x01c8:
            if (n < 13) break;
            return EvItemUsed{rd16(d, 2), rd16(d, 10), rd32(d, 6), rd8(d, 12) != 0};
        case 0x00a8:
            if (n < 7) break;
            return EvItemUsed{rd16(d, 2), rd16(d, 4), 0, rd8(d, 6) != 0};
        case 0x010f: {
            EvSkills ev;
            for (size_t o = 4; o + 37 <= n; o += 37)
                ev.skills.push_back(SkillInfo{rd16(d, o), rd32(d, o + 2), rd16(d, o + 6), rd16(d, o + 10)});
            return ev;
        }
        case 0x010e:
            if (n < 11) break;
            return EvSkillUp{rd16(d, 2), rd16(d, 4), rd16(d, 8)};
        case 0x02b9: {
            if (n < 191) break;
            EvHotkeys ev;
            for (size_t i = 0; i < ev.keys.size(); ++i) {
                const size_t o = 2 + i * 7;
                ev.keys[i] = Hotkey{rd8(d, o), rd32(d, o + 1), rd16(d, o + 5)};
            }
            return ev;
        }
        case 0x0148:
            if (n < 8) break;
            return EvResurrect{rd32(d, 2)};
        default:
            break;
    }
    return std::nullopt;
}

}  // namespace uapad

**Файл:** `src/core/world/world.cpp`
```cpp
#include "core/world/world.hpp"

#include <type_traits>

namespace uapad {

namespace {
constexpr uint16_t kDefaultSpeed = 150;  // DEFAULT_WALK_SPEED in uAthena
}  // namespace

void WorldState::reset(uint32_t selfId) {
    *this = WorldState();
    selfId_ = selfId;
}

void WorldState::clearMap() {
    actors_.clear();
    lastHit_.clear();
    items_.clear();
    sitting_ = false;
    dead_ = false;
}

Cell WorldState::interpolate(Cell from, Cell to, uint16_t speed, uint32_t startMs, uint32_t nowMs) {
    const int steps = cellDistance(from, to);
    if (steps == 0) return to;
    const uint32_t elapsed = nowMs - startMs;
    const uint32_t total = uint32_t(steps) * (speed ? speed : kDefaultSpeed);
    if (elapsed >= total) return to;
    const int done = int(uint64_t(elapsed) * uint64_t(steps) / total);
    return Cell{from.x + (to.x - from.x) * done / steps, from.y + (to.y - from.y) * done / steps};
}

Cell WorldState::selfPos(uint32_t nowMs) const {
    return interpolate(selfFrom_, selfTo_, kDefaultSpeed, selfMoveStartMs_, nowMs);
}

std::optional<Cell> WorldState::actorPos(uint32_t id, uint32_t nowMs) const {
    auto it = actors_.find(id);
    if (it == actors_.end()) return std::nullopt;
    const Actor& a = it->second;
    return interpolate(a.from, a.to, a.speed, a.moveStartMs, nowMs);
}

bool WorldState::isMonster(const Actor& a) const {
    // Mob db ids; pets carry battle_config.pet_hair_style (100) in the hair field.
    return a.cls >= 1001 && a.cls <= 3999 && a.hair == 0 && a.id != ownPet_;
}

std::optional<uint32_t> WorldState::lastHitMs(uint32_t target) const {
    auto it = lastHit_.find(target);
    if (it == lastHit_.end()) return std::nullopt;
    return it->second;
}

std::optional<InvEntry> WorldState::findUsable(uint16_t itemId) const {
    std::optional<InvEntry> best;
    for (const auto& entry : inventory_) {
        const InvEntry& e = entry.second;
        if (e.item != itemId || e.amount == 0 || e.equip) continue;
        if (!best || e.index < best->index) best = e;
    }
    return best;
}

std::optional<SkillInfo> WorldState::skill(uint16_t id) const {
    auto it = skills_.find(id);
    if (it == skills_.end()) return std::nullopt;
    return it->second;
}

const Hotkey& WorldState::hotkey(int slot) const {
    static const Hotkey kEmpty{};
    if (slot < 0 || slot >= kHotkeySlots) return kEmpty;
    return hotkeys_[size_t(slot)];
}

void WorldState::setHotkey(int slot, const Hotkey& key) {
    if (slot >= 0 && slot < kHotkeySlots) hotkeys_[size_t(slot)] = key;
}

void WorldState::apply(const Event& ev, uint32_t nowMs) {
    std::visit(
        [&](const auto& e) {
            using T = std::decay_t<decltype(e)>;
            if constexpr (std::is_same_v<T, EvAuthOk> || std::is_same_v<T, EvMapChange>) {
                clearMap();
                inGame_ = true;
                selfFrom_ = selfTo_ = e.pos;
            } else if constexpr (std::is_same_v<T, EvSelfWalk>) {
                selfFrom_ = e.from;
                selfTo_ = e.to;
                selfMoveStartMs_ = nowMs;
            } else if constexpr (std::is_same_v<T, EvSetPos>) {
                if (e.id == selfId_) {
                    selfFrom_ = selfTo_ = e.pos;
                } else if (auto it = actors_.find(e.id); it != actors_.end()) {
                    it->second.from = it->second.to = e.pos;
                }
            } else if constexpr (std::is_same_v<T, EvVanish>) {
                if (e.id == selfId_) {
                    if (e.type == 1) dead_ = true;
                } else {
                    actors_.erase(e.id);
                    lastHit_.erase(e.id);
                }
            } else if constexpr (std::is_same_v<T, EvActor>) {
                if (e.id == selfId_) return;
                Actor a;
                a.id = e.id;
                a.cls = e.cls;
                a.hair = e.hair;
                a.speed = e.speed ? e.speed : kDefaultSpeed;
                a.from = e.from;
                a.to = e.to;
                a.moveStartMs = nowMs;
                actors_[e.id] = a;
            } else if constexpr (std::is_same_v<T, EvActorMove>) {
                if (auto it = actors_.find(e.id); it != actors_.end()) {
                    it->second.from = e.from;
                    it->second.to = e.to;
                    it->second.moveStartMs = nowMs;
                }
            } else if constexpr (std::is_same_v<T, EvPetInfo>) {
                if (e.type == 0) ownPet_ = e.id;
            } else if constexpr (std::is_same_v<T, EvAction>) {
                if (e.src != selfId_) return;
                if (e.type == 2 || e.type == 3) {
                    sitting_ = e.type == 2;
                } else if (e.dst != 0) {
                    lastHit_[e.dst] = nowMs;
                }
            } else if constexpr (std::is_same_v<T, EvSkillHit>) {
                if (e.src == selfId_ && e.dst != selfId_) lastHit_[e.dst] = nowMs;
            } else if constexpr (std::is_same_v<T, EvGroundItem>) {
                items_[e.id] = GroundItem{e.id, e.item, e.pos};
            } else if constexpr (std::is_same_v<T, EvGroundItemGone>) {
                items_.erase(e.id);
            } else if constexpr (std::is_same_v<T, EvInventory>) {
                for (auto it = inventory_.begin(); it != inventory_.end();) {
                    if (!it->second.equip)
                        it = inventory_.erase(it);
                    else
                        ++it;
                }
                for (const InvEntry& item : e.items) inventory_[item.index] = item;
            } else if constexpr (std::is_same_v<T, EvItemAdd>) {
                auto it = inventory_.find(e.entry.index);
                if (it != inventory_.end() && it->second.item == e.entry.item)
                    it->second.amount = uint16_t(it->second.amount + e.entry.amount);
                else
                    inventory_[e.entry.index] = e.entry;
            } else if constexpr (std::is_same_v<T, EvItemRemove>) {
                if (auto it = inventory_.find(e.index); it != inventory_.end()) {
                    it->second.amount = it->second.amount > e.amount ? uint16_t(it->second.amount - e.amount) : 0;
                    if (it->second.amount == 0) inventory_.erase(it);
                }
            } else if constexpr (std::is_same_v<T, EvItemUsed>) {
                if ((e.user != 0 && e.user != selfId_) || !e.ok) return;
                if (auto it = inventory_.find(e.index); it != inventory_.end()) {
                    it->second.amount = e.remaining;
                    if (e.remaining == 0) inventory_.erase(it);
                }
            } else if constexpr (std::is_same_v<T, EvSkills>) {
                skills_.clear();
                for (const SkillInfo& s : e.skills) skills_[s.id] = s;
            } else if constexpr (std::is_same_v<T, EvSkillUp>) {
                SkillInfo& s = skills_[e.id];
                s.id = e.id;
                s.lv = e.lv;
                s.range = e.range;
            } else if constexpr (std::is_same_v<T, EvHotkeys>) {
                hotkeys_ = e.keys;
            } else if constexpr (std::is_same_v<T, EvResurrect>) {
                if (e.id == selfId_) dead_ = false;
            }
        },
        ev);
}

}  // namespace uapad

```cpp
#include "core/logic/targeting.hpp"

#include <algorithm>
#include <utility>

namespace uapad {

std::vector<uint32_t> targetCandidates(const WorldState& world, uint32_t nowMs,
                                       const std::unordered_map<uint32_t, uint32_t>& blacklistUntil) {
    const Cell me = world.selfPos(nowMs);
    std::vector<std::pair<int, uint32_t>> scored;
    for (const auto& entry : world.actors()) {
        const uint32_t id = entry.first;
        if (!world.isMonster(entry.second)) continue;
        auto bl = blacklistUntil.find(id);
        if (bl != blacklistUntil.end() && int32_t(nowMs - bl->second) < 0) continue;
        if (auto pos = world.actorPos(id, nowMs)) scored.emplace_back(cellDistance(me, *pos), id);
    }
    std::sort(scored.begin(), scored.end());
    std::vector<uint32_t> ids;
    ids.reserve(scored.size());
    for (const auto& s : scored) ids.push_back(s.second);
    return ids;
}

uint32_t cycleTarget(const std::vector<uint32_t>& candidates, uint32_t current, int dir) {
    if (candidates.empty()) return 0;
    auto it = std::find(candidates.begin(), candidates.end(), current);
    if (it == candidates.end()) return candidates.front();
    const long n = long(candidates.size());
    long i = long(it - candidates.begin()) + (dir > 0 ? 1 : -1);
    i = ((i % n) + n) % n;
    return candidates[size_t(i)];
}

bool shouldGiveUp(const WorldState& world, uint32_t target, uint32_t attackSinceMs, uint32_t nowMs, uint32_t giveUpMs) {
    uint32_t ref = attackSinceMs;
    if (auto hit = world.lastHitMs(target); hit && int32_t(*hit - ref) > 0) ref = *hit;
    return nowMs - ref >= giveUpMs;
}

}  // namespace uapad

struct SlotDecision {
    enum class Kind { Deny, Send, Approach };
    Kind kind = Kind::Deny;
    Bytes packet;            // Send: the request to send now
    uint32_t newTarget = 0;  // != 0: the controller should adopt this monster as its target
    uint32_t actor = 0;      // Approach: walk until within `range` of this actor, then cast
    bool ground = false;     // Approach: cast on the actor's cell instead of on the actor
    uint16_t skill = 0;
    uint16_t lv = 0;
    int range = 1;
    std::string reason;      // Deny: why, for the log
};

// What a hotkey slot does right now. `target`: the current live target or 0; `nearest`: the nearest
// candidate or 0 (used only by enemy skills when there is no target).
SlotDecision decideSlot(const Hotkey& key, const WorldState& world, uint32_t target, uint32_t nearest,
                        const std::vector<uint16_t>& groundSelf, uint32_t nowMs);

}  // namespace uapad
```

```cpp
#include "core/logic/slots.hpp"

#include <algorithm>

#include "core/proto/c2s.hpp"

namespace uapad {
namespace {

constexpr uint32_t kInfEnemy = 1;
constexpr uint32_t kInfGround = 2;
constexpr uint32_t kInfSelf = 4;
constexpr uint32_t kInfSupport = 16;

SlotDecision deny(std::string why) {
    SlotDecision d;
    d.reason = std::move(why);
    return d;
}

SlotDecision send(Bytes packet) {
    SlotDecision d;
    d.kind = SlotDecision::Kind::Send;
    d.packet = std::move(packet);
    return d;
}

}  // namespace

SlotDecision decideSlot(const Hotkey& key, const WorldState& world, uint32_t target, uint32_t nearest,
                        const std::vector<uint16_t>& groundSelf, uint32_t nowMs) {
    if (key.id == 0) return deny("empty slot");
    if (key.type == 0) {
        auto item = world.findUsable(uint16_t(key.id));
        if (!item) return deny("item " + std::to_string(key.id) + " is not in the inventory");
        return send(buildUseItem(item->index, world.selfId()));
    }
    auto sk = world.skill(uint16_t(key.id));
    if (!sk || sk->lv == 0) return deny("skill " + std::to_string(key.id) + " is not learned");
    const uint16_t id = sk->id;
    const uint16_t lv = key.lv == 0 ? sk->lv : std::min(key.lv, sk->lv);
    const Cell me = world.selfPos(nowMs);
    const int reach = std::max(1, int(sk->range));

    auto castOn = [&](uint32_t actor, bool ground, uint32_t newTarget) {
        auto pos = world.actorPos(actor, nowMs);
        if (!pos) return deny("target is gone");
        SlotDecision d;
        d.newTarget = newTarget;
        if (cellDistance(me, *pos) <= reach) {
            d.kind = SlotDecision::Kind::Send;
            d.packet = ground ? buildSkillToPos(id, lv, *pos) : buildSkillToId(id, lv, actor);
        } else {
            d.kind = SlotDecision::Kind::Approach;
            d.actor = actor;
            d.ground = ground;
            d.skill = id;
            d.lv = lv;
            d.range = reach;
        }
        return d;
    };

    if (sk->inf & kInfGround) {
        const bool underSelf = std::find(groundSelf.begin(), groundSelf.end(), id) != groundSelf.end();
        if (underSelf || target == 0) return send(buildSkillToPos(id, lv, me));
        return castOn(target, true, 0);
    }
    if (sk->inf & kInfEnemy) {
        if (target != 0) return castOn(target, false, 0);
        if (nearest != 0) return castOn(nearest, false, nearest);
        return deny("no monster for skill " + std::to_string(id));
    }
    if (sk->inf & (kInfSelf | kInfSupport)) return send(buildSkillToId(id, lv, world.selfId()));
    return deny("skill " + std::to_string(id) + " is passive");
}

}  // namespace uapad

```cpp
#include "core/logic/controller.hpp"

#include <algorithm>
#include <cmath>

#include "core/logic/slots.hpp"
#include "core/logic/targeting.hpp"
#include "core/proto/c2s.hpp"

namespace uapad {
namespace {

constexpr float kTriggerHeld = 0.5f;
constexpr uint32_t kSlotIntervalMs = 150;
constexpr uint32_t kApproachStepMs = 250;
constexpr uint32_t kApproachTimeoutMs = 5000;
constexpr int kPickupRadius = 10;
constexpr int kPickupReach = 1;
constexpr uint16_t kFaceButtons[4] = {kPadA, kPadB, kPadX, kPadY};
constexpr uint16_t kActionButtons = kPadA | kPadB | kPadX | kPadY | kPadLeft | kPadRight;
constexpr int kSlotBase[] = {0, 0, 4, 9, 13};  // by Mod: None, LT, RT, LB, RB

bool due(const std::optional<uint32_t>& last, uint32_t now, uint32_t interval) {
    return !last || now - *last >= interval;
}

}  // namespace

Controller::Controller(const Config& cfg) : cfg_(cfg), enabled_(cfg.enabled) {}

void Controller::deny(TickOutput& out, const std::string& why) {
    if (out.rumble == Rumble::None) out.rumble = Rumble::Denied;
    out.notes.push_back("denied: " + why);
}

bool Controller::targetAlive(const WorldState& world) const {
    return target_ != 0 && world.actors().count(target_) != 0;
}

void Controller::setTarget(uint32_t id, TickOutput& out) {
    if (id == target_) return;
    target_ = id;
    attackSent_ = false;
    if (id == 0) return;
    if (out.rumble == Rumble::None) out.rumble = Rumble::TargetSwitch;
    out.notes.push_back("target " + std::to_string(id));
}

void Controller::updateModifier(bool lt, bool rt, uint16_t buttons) {
    auto held = [&](Mod m) {
        switch (m) {
            case Mod::LT: return lt;
            case Mod::RT: return rt;
            case Mod::LB: return (buttons & kPadLB) != 0;
            case Mod::RB: return (buttons & kPadRB) != 0;
            case Mod::None: break;
        }
        return false;
    };
    if (mod_ != Mod::None && held(mod_)) return;  // the first pressed modifier keeps priority
    mod_ = Mod::None;
    for (Mod m : {Mod::LT, Mod::RT, Mod::LB, Mod::RB}) {
        if (held(m)) {
            mod_ = m;
            break;
        }
    }
}

TickOutput Controller::tick(const PadState& pad, const WorldState& world, const ViewInfo& view, uint32_t now) {
    TickOutput out;
    const uint16_t buttons = pad.connected ? pad.buttons : 0;
    const uint16_t down = uint16_t(buttons & ~prevButtons_);
    prevButtons_ = buttons;
    updateModifier(pad.connected && pad.lt > kTriggerHeld, pad.connected && pad.rt > kTriggerHeld, buttons);

    if (down & kPadBack) {
        enabled_ = !enabled_;
        out.rumble = enabled_ ? Rumble::AutoOn : Rumble::AutoOff;
        out.notes.push_back(enabled_ ? "pad on" : "pad off");
        if (!enabled_) {
            autoAttack_ = false;
            wantAttack_ = false;
        }
    }
    if (!enabled_ || !pad.connected || !view.focused || !world.inGame() || world.dead()) {
        walking_ = false;
        approach_.reset();
        return out;
    }
    walk(pad, world, view, now, out);
    handleButtons(down, world, now, out);
    stepApproach(world, now, out);
    maintainTarget(world, now, out);
    return out;
}

void Controller::walk(const PadState& pad, const WorldState& world, const ViewInfo& view, uint32_t now,
                      TickOutput& out) {
    const float mag = std::sqrt(pad.lx * pad.lx + pad.ly * pad.ly);
    if (mag > cfg_.deadzone && view.width > 0 && view.height > 0) {
        const bool starting = !walking_;
        if (starting) {
            walking_ = true;
            approach_.reset();
            attackSent_ = false;
            if (!autoAttack_) wantAttack_ = false;
        }
        const float radius = cfg_.walkRadius * float(std::min(view.width, view.height));
        const int cx = view.width / 2;
        const int cy = view.height / 2;
        out.mouse.active = true;
        out.mouse.lmb = true;
        if (starting && cfg_.press == PressMode::Center) {
            out.mouse.x = cx;
            out.mouse.y = cy;
        } else {
            out.mouse.x = cx + int(std::lround(pad.lx / mag * radius));
            out.mouse.y = cy - int(std::lround(pad.ly / mag * radius));
        }
        return;
    }
    if (walking_) {
        walking_ = false;
        out.packets.push_back(buildWalk(world.selfPos(now)));  // stop where we are
        out.notes.push_back("walk stop");
    }
}

void Controller::handleButtons(uint16_t down, const WorldState& world, uint32_t now, TickOutput& out) {
    if (down & kActionButtons) approach_.reset();
    if (mod_ != Mod::None) {
        for (int i = 0; i < 4; ++i)
            if (down & kFaceButtons[i]) useSlot(kSlotBase[int(mod_)] + i, world, now, out);
    } else {
        if (down & kPadA) {
            if (!targetAlive(world)) {
                auto c = targetCandidates(world, now, blacklist_);
                if (c.empty())
                    deny(out, "no monsters around");
                else
                    setTarget(c.front(), out);
            }
            if (targetAlive(world)) {
                wantAttack_ = true;
                attackSent_ = false;
            }
        }
        if (down & kPadB) pickup(world, now, out);
        if (down & kPadX) {
            autoAttack_ = !autoAttack_;
            wantAttack_ = autoAttack_;
            out.rumble = autoAttack_ ? Rumble::AutoOn : Rumble::AutoOff;
            out.notes.push_back(autoAttack_ ? "auto-attack on" : "auto-attack off");
        }
        if (down & kPadY) {
            out.packets.push_back(buildAction(0, world.sitting() ? kActionStand : kActionSit));
            attackSent_ = false;
        }
    }
    if (down & (kPadLeft | kPadRight)) {
        const uint32_t next = cycleTarget(targetCandidates(world, now, blacklist_), target_, (down & kPadRight) ? 1 : -1);
        if (next == 0) {
            deny(out, "no monsters around");
        } else {
            setTarget(next, out);
            wantAttack_ = true;
            attackSent_ = false;
        }
    }
}

void Controller::useSlot(int slot, const WorldState& world, uint32_t now, TickOutput& out) {
    const Hotkey& key = world.hotkey(slot);
    if (key.id == 0) {
        deny(out, "slot " + std::to_string(slot) + " is empty");
        return;
    }
    if (!due(lastSlotMs_, now, kSlotIntervalMs)) return;
    lastSlotMs_ = now;
    const uint32_t target = targetAlive(world) ? target_ : 0;
    uint32_t nearest = 0;
    if (target == 0) {
        auto c = targetCandidates(world, now, blacklist_);
        if (!c.empty()) nearest = c.front();
    }
    SlotDecision d = decideSlot(key, world, target, nearest, cfg_.groundSelf, now);
    if (d.newTarget != 0) setTarget(d.newTarget, out);
    switch (d.kind) {
        case SlotDecision::Kind::Deny:
            deny(out, d.reason);
            break;
        case SlotDecision::Kind::Send:
            out.packets.push_back(std::move(d.packet));
            break;
        case SlotDecision::Kind::Approach: {
            Approach ap;
            ap.id = d.actor;
            ap.ground = d.ground;
            ap.skill = d.skill;
            ap.lv = d.lv;
            ap.range = d.range;
            ap.startMs = now;
            approach_ = ap;
            out.notes.push_back("approaching for skill " + std::to_string(d.skill));
            break;
        }
    }
}

void Controller::pickup(const WorldState& world, uint32_t now, TickOutput& out) {
    const Cell me = world.selfPos(now);
    const GroundItem* best = nullptr;
    int bestDist = 0;
    for (const auto& entry : world.groundItems()) {
        const GroundItem& item = entry.second;
        const int d = cellDistance(me, item.pos);
        if (d > kPickupRadius) continue;
        if (!best || d < bestDist || (d == bestDist && item.id < best->id)) {
            best = &item;
            bestDist = d;
        }
    }
    if (!best) {
        deny(out, "nothing to pick up");
        return;
    }
    if (bestDist <= kPickupReach) {
        out.packets.push_back(buildTakeItem(best->id));
        return;
    }
    Approach ap;
    ap.pickup = true;
    ap.id = best->id;
    ap.range = kPickupReach;
    ap.startMs = now;
    approach_ = ap;
    out.notes.push_back("walking to item " + std::to_string(best->id));
}

void Controller::stepApproach(const WorldState& world, uint32_t now, TickOutput& out) {
    if (!approach_) return;
    Approach& ap = *approach_;
    if (now - ap.startMs >= kApproachTimeoutMs) {
        out.notes.push_back("approach timed out");
        approach_.reset();
        return;
    }
    std::optional<Cell> goal;
    if (ap.pickup) {
        auto it = world.groundItems().find(ap.id);
        if (it != world.groundItems().end()) goal = it->second.pos;
    } else {
        goal = world.actorPos(ap.id, now);
    }
    if (!goal) {
        out.notes.push_back("approach target is gone");
        approach_.reset();
        return;
    }
    if (cellDistance(world.selfPos(now), *goal) <= ap.range) {
        if (ap.pickup)
            out.packets.push_back(buildTakeItem(ap.id));
        else if (ap.ground)
            out.packets.push_back(buildSkillToPos(ap.skill, ap.lv, *goal));
        else
            out.packets.push_back(buildSkillToId(ap.skill, ap.lv, ap.id));
        approach_.reset();
        return;
    }
    if (due(ap.lastStepMs, now, kApproachStepMs)) {
        out.packets.push_back(buildWalk(*goal));
        ap.lastStepMs = now;
    }
}

void Controller::maintainTarget(const WorldState& world, uint32_t now, TickOutput& out) {
    for (auto it = blacklist_.begin(); it != blacklist_.end();) {
        if (int32_t(now - it->second) >= 0)
            it = blacklist_.erase(it);
        else
            ++it;
    }
    if (target_ != 0 && !targetAlive(world)) {
        out.notes.push_back("target " + std::to_string(target_) + " is gone");
        target_ = 0;
        attackSent_ = false;
        if (!autoAttack_) wantAttack_ = false;
    }
    if (target_ != 0 && attackSent_ &&
        shouldGiveUp(world, target_, attackSinceMs_, now, uint32_t(cfg_.giveUpSeconds * 1000.0f))) {
        blacklist_[target_] = now + uint32_t(cfg_.blacklistSeconds * 1000.0f);
        out.notes.push_back("giving up on " + std::to_string(target_));
        target_ = 0;
        attackSent_ = false;
        if (!autoAttack_) wantAttack_ = false;
    }
    const bool idle = !walking_ && !approach_ && !world.sitting();
    if (autoAttack_ && target_ == 0 && idle) {
        auto c = targetCandidates(world, now, blacklist_);
        if (!c.empty()) {
            setTarget(c.front(), out);
            wantAttack_ = true;
        }
    }
    if (target_ != 0 && wantAttack_ && !attackSent_ && idle &&
        due(lastAttackMs_, now, uint32_t(cfg_.attackIntervalMs))) {
        out.packets.push_back(buildAction(target_, kActionAttack));
        lastAttackMs_ = now;
        attackSent_ = true;
        attackSinceMs_ = now;
    }
}

}  // namespace uapad

Запросы отправляются, только когда поток клиента стоит на границе пакета и оба потока целы; запрос, прождавший дольше 500 мс, выбрасывается.

// Protocol state of the client's sockets plus the controller. Called from the game thread only.
class Session {
public:
    using SocketId = uintptr_t;

    explicit Session(const Config& cfg);

    void onClientSent(SocketId s, const uint8_t* data, size_t n, uint32_t nowMs);  // bytes really sent
    void onServerData(SocketId s, const uint8_t* data, size_t n, uint32_t nowMs);  // bytes really received
    void onClosed(SocketId s);

    // Runs the controller. Its requests are queued for injection (and still listed in the output).
    TickOutput tick(const PadState& pad, const ViewInfo& view, uint32_t nowMs);
    // Queued requests that may go out now; requests that waited longer than 500 ms are dropped.
    std::vector<Bytes> takeInjectable(uint32_t nowMs);
    bool canInject() const;
    void markInjectBroken();

    SocketId mapSocket() const { return mapSocket_; }
    const WorldState& world() const { return world_; }
    std::vector<std::string> takeLog();

private:
    struct Conn {
        enum class Kind { Unknown, Map, Other };
        Kind kind = Kind::Unknown;
        Bytes head;  // first client bytes, until the connection can be classified
        std::unique_ptr<StreamFramer> up;    // client -> server
        std::unique_ptr<StreamFramer> down;  // server -> client
    };

    void feedUp(Conn& c, const uint8_t* data, size_t n);

    WorldState world_;
    Controller controller_;
    std::unordered_map<SocketId, Conn> conns_;
    SocketId mapSocket_ = 0;
    bool downOk_ = false;
    bool injectOk_ = false;
    std::deque<std::pair<uint32_t, Bytes>> queue_;
    std::vector<std::string> log_;
};

}  // namespace uapad

```cpp
#include "core/session.hpp"

#include <cstdio>

#include "core/proto/c2s.hpp"
#include "core/proto/s2c_parser.hpp"

namespace uapad {
namespace {

constexpr uint32_t kStaleMs = 500;

std::string hex16(uint16_t v) {
    char b[8];
    std::snprintf(b, sizeof b, "0x%04x", unsigned(v));
    return b;
}

}  // namespace

Session::Session(const Config& cfg) : controller_(cfg) {}

void Session::onClientSent(SocketId s, const uint8_t* data, size_t n, uint32_t nowMs) {
    (void)nowMs;
    if (n == 0) return;
    Conn& c = conns_[s];
    if (c.kind == Conn::Kind::Other) return;
    if (c.kind == Conn::Kind::Map) {
        feedUp(c, data, n);
        return;
    }
    c.head.insert(c.head.end(), data, data + n);
    if (c.head.size() < 2) return;
    if (rd16(c.head.data(), 0) != 0x009b) {
        c.kind = Conn::Kind::Other;  // login or char server: never parsed, never logged
        Bytes().swap(c.head);
        return;
    }
    if (mapSocket_ != 0 && mapSocket_ != s) conns_.erase(mapSocket_);
    c.kind = Conn::Kind::Map;
    c.up = std::make_unique<StreamFramer>(Direction::ClientToServer);
    c.down = std::make_unique<StreamFramer>(Direction::ServerToClient, 4);  // raw account id first
    mapSocket_ = s;
    downOk_ = true;
    injectOk_ = true;
    queue_.clear();
    Bytes first;
    first.swap(c.head);
    feedUp(c, first.data(), first.size());
}

void Session::feedUp(Conn& c, const uint8_t* data, size_t n) {
    std::vector<Bytes> packets;
    if (!c.up->feed(data, n, packets) && injectOk_) {
        injectOk_ = false;
        log_.push_back("client stream out of sync at " + hex16(c.up->badId()) + "; pad requests are off");
    }
    for (const Bytes& p : packets) {
        if (auto account = parseWantToConnection(p)) {
            world_.reset(*account);
            log_.push_back("map server connection, account " + std::to_string(*account));
        } else if (auto change = parseHotkeyChange(p)) {
            world_.setHotkey(change->index, change->key);
        }
    }
}

void Session::onServerData(SocketId s, const uint8_t* data, size_t n, uint32_t nowMs) {
    if (n == 0 || s != mapSocket_ || !downOk_) return;
    auto it = conns_.find(s);
    if (it == conns_.end() || !it->second.down) return;
    std::vector<Bytes> packets;
    if (!it->second.down->feed(data, n, packets)) {
        downOk_ = false;
        log_.push_back("server stream out of sync at " + hex16(it->second.down->badId()) + "; pad requests are off");
    }
    for (const Bytes& p : packets)
        if (auto ev = parseS2C(p)) world_.apply(*ev, nowMs);
}

void Session::onClosed(SocketId s) {
    conns_.erase(s);
    if (s != mapSocket_) return;
    mapSocket_ = 0;
    downOk_ = false;
    injectOk_ = false;
    queue_.clear();
    log_.push_back("map server connection closed");
}

TickOutput Session::tick(const PadState& pad, const ViewInfo& view, uint32_t nowMs) {
    TickOutput out = controller_.tick(pad, world_, view, nowMs);
    if (out.packets.empty()) return out;
    if (mapSocket_ != 0 && downOk_ && injectOk_) {
        for (const Bytes& p : out.packets) queue_.emplace_back(nowMs, p);
    } else {
        log_.push_back("dropped " + std::to_string(out.packets.size()) + " request(s): no healthy map server connection");
    }
    return out;
}

bool Session::canInject() const {
    if (mapSocket_ == 0 || !downOk_ || !injectOk_) return false;
    auto it = conns_.find(mapSocket_);
    return it != conns_.end() && it->second.up && it->second.up->atBoundary();
}

std::vector<Bytes> Session::takeInjectable(uint32_t nowMs) {
    std::vector<Bytes> ready;
    while (!queue_.empty() && nowMs - queue_.front().first > kStaleMs) {
        log_.push_back("dropped a request that waited too long");
        queue_.pop_front();
    }
    if (!canInject()) return ready;
    while (!queue_.empty()) {
        ready.push_back(std::move(queue_.front().second));
        queue_.pop_front();
    }
    return ready;
}

void Session::markInjectBroken() {
    injectOk_ = false;
    queue_.clear();
    log_.push_back("could not send a request; pad requests are off until the next map server connection");
}

std::vector<std::string> Session::takeLog() {
    std::vector<std::string> out;
    out.swap(log_);
    return out;
}

}  // namespace uapad

#include <algorithm>
#include <exception>
#include <fstream>
#include <memory>
#include <sstream>
#include <string>
#include <vector>

#include "core/bytes.hpp"
#include "core/config/config.hpp"
#include "core/session.hpp"
#include "core/version.hpp"
#include "win/hooks.hpp"
#include "win/log.hpp"
#include "win/xinput_pad.hpp"

namespace uapad::runtime {
namespace {

constexpr size_t kMaxPendingButtons = 16;

struct State {
    bool initDone = false;
    bool failed = false;
    DWORD gameThread = 0;
    bool warnedThread = false;
    HWND hwnd = nullptr;
    Config cfg;
    std::unique_ptr<Session> session;
    XInputPad pad;
    VirtualMouse mouse;        // what the client currently gets from us
    bool reportedLmb = false;  // last virtual LMB state handed to the client
    std::vector<DIDEVICEOBJECTDATA> pendingButtons;  // for clients that read the mouse buffered
    bool loggedConnected = false;
    uint16_t loggedButtons = 0;
    bool ticked = false;
    DWORD lastTickMs = 0;
    unsigned long nState = 0, nData = 0, nCursor = 0, nPump = 0, nRecv = 0, nSend = 0;
    DWORD lastDiagMs = 0;
};

State& S() {
    static State s;
    return s;
}

std::string exeDir() {
    char path[MAX_PATH] = {0};
    GetModuleFileNameA(nullptr, path, MAX_PATH);
    const std::string p(path);
    const size_t slash = p.find_last_of("\\/");
    return slash == std::string::npos ? std::string() : p.substr(0, slash + 1);
}

std::string readFile(const std::string& path) {
    std::ifstream f(path, std::ios::binary);
    std::ostringstream ss;
    ss << f.rdbuf();
    return ss.str();
}

bool onGameThread() {
    State& s = S();
    if (GetCurrentThreadId() == s.gameThread) return true;
    if (!s.warnedThread) {
        s.warnedThread = true;
        LOG_INFO("a hook was called from a non-game thread (%lu); such calls are ignored",
                 (unsigned long)GetCurrentThreadId());
    }
    return false;
}

void fail(const char* where) {
    State& s = S();
    if (!s.failed) LOG_ERROR("internal error in %s; pass-through until the client restarts", where);
    s.failed = true;
    s.mouse = VirtualMouse{};
    s.pendingButtons.clear();
    s.pad.stopRumble();
}

template <class F>
void guarded(const char* where, F&& body) {
    State& s = S();
    if (!s.initDone || s.failed) return;
    try {
        body();
    } catch (const std::exception& e) {
        LOG_ERROR("%s: %s", where, e.what());
        fail(where);
    } catch (...) {
        fail(where);
    }
}

ViewInfo currentView() {
    State& s = S();
    ViewInfo v;
    if (!s.hwnd) return v;
    v.focused = GetForegroundWindow() == s.hwnd;
    RECT r;
    if (GetClientRect(s.hwnd, &r)) {
        v.width = r.right - r.left;
        v.height = r.bottom - r.top;
    }
    return v;
}

void applyMouse(const VirtualMouse& m) {
    State& s = S();
    const bool lmb = m.active && m.lmb;
    if (lmb != s.reportedLmb) {
        if (s.cfg.buttons == ButtonChannel::DirectInput) {
            DIDEVICEOBJECTDATA ev{};
            ev.dwOfs = DIMOFS_BUTTON0;
            ev.dwData = lmb ? 0x80 : 0x00;
            ev.dwTimeStamp = GetTickCount();
            if (s.pendingButtons.size() >= kMaxPendingButtons) s.pendingButtons.erase(s.pendingButtons.begin());
            s.pendingButtons.push_back(ev);
        } else if (s.hwnd) {
            PostMessageA(s.hwnd, lmb ? WM_LBUTTONDOWN : WM_LBUTTONUP, lmb ? MK_LBUTTON : 0, MAKELPARAM(m.x, m.y));
        }
        s.reportedLmb = lmb;
    } else if (lmb && s.cfg.buttons == ButtonChannel::Messages && s.hwnd && (m.x != s.mouse.x || m.y != s.mouse.y)) {
        PostMessageA(s.hwnd, WM_MOUSEMOVE, MK_LBUTTON, MAKELPARAM(m.x, m.y));
    }
    s.mouse = m;
}

void flushPackets() {
    State& s = S();
    std::vector<Bytes> ready = s.session->takeInjectable(GetTickCount());
    if (ready.empty()) return;
    const SOCKET sock = SOCKET(s.session->mapSocket());
    for (const Bytes& p : ready) {
        if (!hooks::sendAll(sock, p.data(), int(p.size()))) {
            LOG_ERROR("sending a pad request failed (WSA error %d)", hooks::lastError());
            s.session->markInjectBroken();
            return;
        }
        LOG_DEBUG("sent 0x%04x (%u bytes)", unsigned(rd16(p.data(), 0)), unsigned(p.size()));
    }
}

void logDiagnostics(DWORD now) {
    State& s = S();
    if (s.lastDiagMs != 0 && now - s.lastDiagMs < 10000) return;
    s.lastDiagMs = now;
    LOG_INFO("diag: mouse GetDeviceState=%lu GetDeviceData=%lu | GetCursorPos=%lu | PeekMessageA=%lu | recv=%lu send=%lu | map=%s self=%lu",
             s.nState, s.nData, s.nCursor, s.nPump, s.nRecv, s.nSend, s.session->mapSocket() ? "yes" : "no",
             (unsigned long)s.session->world().selfId());
}

void logPad(const PadState& p) {
    State& s = S();
    if (p.connected != s.loggedConnected) {
        s.loggedConnected = p.connected;
        LOG_INFO("gamepad %s", p.connected ? "connected" : "disconnected");
    }
    if (p.buttons != s.loggedButtons) {
        s.loggedButtons = p.buttons;
        LOG_DEBUG("buttons 0x%04x", unsigned(p.buttons));
    }
}

void tick() {
    State& s = S();
    const DWORD now = GetTickCount();
    if (s.ticked && now - s.lastTickMs < 5) return;  // the client may poll several times per frame
    s.ticked = true;
    s.lastTickMs = now;
    const PadState pad = s.pad.poll();
    logPad(pad);
    const TickOutput out = s.session->tick(pad, currentView(), now);
    for (const std::string& note : out.notes) LOG_INFO("%s", note.c_str());
    for (const std::string& line : s.session->takeLog()) LOG_INFO("%s", line.c_str());
    if (s.cfg.rumble && out.rumble != Rumble::None) s.pad.rumble(out.rumble, now);
    s.pad.update(now);
    applyMouse(out.mouse);
    flushPackets();
    logDiagnostics(now);
}

}  // namespace

bool healthy() { return S().initDone && !S().failed; }

void init() {
    State& s = S();
    if (s.initDone || s.failed) return;
    try {
        const std::string dir = exeDir();
        s.cfg = parseConfig(readFile(dir + "uaro-pad.ini"));
        wlog::open(dir + "uaro-pad.log", s.cfg.logLevel);
        LOG_INFO("uaRO Pad %s", version());
        s.gameThread = GetCurrentThreadId();
        s.session = std::make_unique<Session>(s.cfg);
        if (!s.cfg.enabled) LOG_INFO("starts switched off ([general] enabled = 0); press Back to switch on");
        hooks::install();
        if (s.pad.load())
            LOG_INFO("XInput: %s", s.pad.dllName());
        else
            LOG_INFO("XInput not found: gamepad unavailable");
        s.initDone = true;
    } catch (...) {
        s.failed = true;
        LOG_ERROR("init failed; pass-through only");
    }
}

void setGameWindow(HWND hwnd) {
    State& s = S();
    if (s.hwnd == hwnd) return;
    s.hwnd = hwnd;
    LOG_INFO("game window %p", static_cast<void*>(hwnd));
}

void onMouseState(DWORD cb, LPVOID data) {
    State& s = S();
    if (s.nState++ == 0) LOG_INFO("first mouse GetDeviceState, %lu bytes", (unsigned long)cb);
    guarded("mouse state", [&] {
        if (!onGameThread()) return;
        tick();
        if (!s.mouse.active || !data || cb < sizeof(DIMOUSESTATE)) return;
        auto* st = static_cast<DIMOUSESTATE*>(data);
        st->lX = 0;  // the real mouse must not drag the cursor away from the walking point
        st->lY = 0;
        if (s.cfg.buttons == ButtonChannel::DirectInput) st->rgbButtons[0] = s.mouse.lmb ? 0x80 : 0x00;
    });
}

void onMouseData(DWORD cbObjectData, LPDIDEVICEOBJECTDATA rgdod, LPDWORD inOut, DWORD capacity, DWORD flags) {
    State& s = S();
    if (s.nData++ == 0)
        LOG_INFO("first mouse GetDeviceData: object %lu bytes, capacity %lu, flags 0x%lx", (unsigned long)cbObjectData,
                 (unsigned long)capacity, (unsigned long)flags);
    guarded("mouse data", [&] {
        if (!onGameThread()) return;
        tick();
        if (!rgdod || !inOut || s.pendingButtons.empty() || cbObjectData < sizeof(DIDEVICEOBJECTDATA)) return;
        DWORD filled = *inOut;
        size_t used = 0;
        while (used < s.pendingButtons.size() && filled < capacity) {
            auto* dst = reinterpret_cast<DIDEVICEOBJECTDATA*>(reinterpret_cast<BYTE*>(rgdod) + size_t(filled) * cbObjectData);
            *dst = s.pendingButtons[used++];
            ++filled;
        }
        *inOut = filled;
        if (!(flags & DIGDD_PEEK)) s.pendingButtons.erase(s.pendingButtons.begin(), s.pendingButtons.begin() + long(used));
    });
}

void onGetCursorPos(LPPOINT p) {
    State& s = S();
    ++s.nCursor;
    guarded("cursor", [&] {
        if (!p || !s.mouse.active || !s.hwnd || !onGameThread()) return;
        POINT pt{s.mouse.x, s.mouse.y};
        if (ClientToScreen(s.hwnd, &pt)) *p = pt;
    });
}

void onMessagePump() {
    State& s = S();
    ++s.nPump;
    guarded("message pump", [&] {
        if (onGameThread() && (!s.ticked || GetTickCount() - s.lastTickMs >= 50)) tick();
    });
}

void onRecv(SOCKET sock, const char* buf, int n) {
    State& s = S();
    ++s.nRecv;
    guarded("recv", [&] {
        if (n > 0 && onGameThread())
            s.session->onServerData(uintptr_t(sock), reinterpret_cast<const uint8_t*>(buf), size_t(n), GetTickCount());
    });
}

void onSent(SOCKET sock, const char* buf, int n) {
    State& s = S();
    ++s.nSend;
    guarded("send", [&] {
        if (n <= 0 || !onGameThread()) return;
        s.session->onClientSent(uintptr_t(sock), reinterpret_cast<const uint8_t*>(buf), size_t(n), GetTickCount());
        flushPackets();
    });
}

void onSentBuffers(SOCKET sock, LPWSABUF bufs, DWORD count, DWORD sent) {
    if (!bufs) return;
    std::string joined;
    for (DWORD i = 0; i < count && joined.size() < sent; ++i)
        joined.append(bufs[i].buf, std::min<size_t>(bufs[i].len, sent - joined.size()));
    onSent(sock, joined.data(), int(joined.size()));
}

void onClose(SOCKET sock) {
    State& s = S();
    guarded("close", [&] {
        if (onGameThread()) s.session->onClosed(uintptr_t(sock));
    });
}

}  // namespace uapad::runtime

## Удаление

Удалите `dinput.dll` и `uaro-pad.ini` из папки клиента. Сам клиент модуль не меняет.

## Управление

| Кнопка | Действие |
|---|---|
| Левый стик | ходьба: вверх на стике — вверх на экране; отпустили — остановка |
| A | атаковать текущую цель или ближайшего монстра |
| D-pad → / ← | следующий / предыдущий монстр |
| X | автоатака вкл/выкл |
| B | подобрать ближайший предмет |
| Y | сесть / встать |
| LT / RT + A, B, X, Y | слоты F1–F4 / F5–F8 первого ряда панели |
| LB / RB + A, B, X, Y | слоты F1–F4 / F5–F8 второго ряда панели |
| Back | выключить / включить модуль |

Скиллы и предметы раскладываются на панель горячих клавиш как обычно, мышкой. Скилл по врагу летит в текущую цель (или в ближайшего монстра), баффы и лечение — на себя, наземные скиллы — под цель. Safety Wall, Pneuma, Warp Portal и Sanctuary ставятся под себя; список меняется в `uaro-pad.ini`.

## Настройки

`uaro-pad.ini` — пояснения к каждому ключу в самом файле. После правки перезапустите клиент.

## Если что-то не так

- Лог пишется в `uaro-pad.log` в папке клиента и перезаписывается при каждом запуске. Подробный лог — `log_level = debug`.
- Персонаж атакует или заговаривает с НПЦ вместо шага — попробуйте `press = center` в разделе `[stick]`.
- Модуль ничего не делает — проверьте, что окно клиента активно и модуль не выключен кнопкой Back.
- Антивирус удалил или заблокировал `dinput.dll` — добавьте папку клиента в исключения.

## Ограничения версии 0.1

- Экипировка на панели (быстрая смена оружия) с геймпада не срабатывает.
- Баффы и лечение — только на себя.
- НПЦ со спрайтом монстра может попасть в цели: через 4 секунды модуль его бросает.
- Меню, диалоги НПЦ и чат — мышью и клавиатурой.

- [ ] **Step 6: Передать пользователю архив и чек-лист M1–M4**

Передать `dist/out/uaro-pad-0.1.0.zip` (например, `scp root@<сервер>:/root/uaro-gamepad/dist/out/uaro-pad-0.1.0.zip .`). Пользователь распаковывает архив в папку клиента (заменяя диагностическую `dinput.dll`) и проходит чек-лист:

**M1 — ходьба**
1. Стик в восемь сторон: персонаж идёт туда, куда наклонён стик (вверх — к верху экрана). Повернуть камеру правой кнопкой мыши: направление по-прежнему совпадает с экраном.
2. Отпустить стик: персонаж останавливается примерно в пределах клетки.
3. Пройти сквозь группу монстров, мимо НПЦ и рядом с открытым окном инвентаря. Записать, бывает ли атака, разговор или клик по окну вместо шага. Если часто — попробовать `[stick] press = center`. Если и это не помогает — сообщить: тогда нужен вариант «б» или «в» из спецификации (отдельный план).
4. Пока стик не тронут, мышь и клавиатура работают как обычно.

**M2 — автоцель**
1. A рядом с несколькими монстрами: атакуется ближайший, геймпад коротко вибрирует.
2. D-pad → / ←: атака переходит на следующего / предыдущего монстра.
3. X: после смерти цели сразу берётся следующая; повторное X выключает автоатаку.
4. Цель за стеной или НПЦ со спрайтом монстра: примерно через 4 секунды модуль её бросает.

**M3 — слоты**
1. Разложить мышкой скиллы и предметы в первые 8 слотов двух рядов панели. LT/RT/LB/RB + A/B/X/Y срабатывают по таблице из README.
2. Скилл ближнего боя по далёкой цели: персонаж подходит и применяет скилл.
3. Бафф или лечение — на себя.
4. Наземный скилл — под цель; Safety Wall и Pneuma — под себя.
5. Зелье используется; когда зелья кончились, кнопка даёт слабую вибрацию.

**M4 — остальное**
1. B подбирает ближайший предмет (подходит, если он дальше клетки).
2. Y: сесть / встать.
3. Back выключает и включает модуль (вибрация).
4. Два клиента одновременно: геймпад управляет тем окном, которое активно.
5. Отключить и снова подключить геймпад: модуль его подхватывает.

При любой проблеме прислать `uaro-pad.log` (при необходимости с `log_level = debug`) и описать, что делали.
